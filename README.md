# 文系数学トレーナー v0.1

タッチペン対応の初期実装です。

## 収録機能
- 解法方針の選択
- 手書き途中式キャンバス
- ペン・消しゴム・Undo・全消去・方眼
- 3段階ヒント
- 最終解答の自動採点
- 自己採点と誤答原因記録
- 端末内の学習履歴・下書き保存
- 分野別進捗・失点原因ダッシュボード
- PWA・オフラインキャッシュ

## 使い方
最も簡単な確認方法は `index.html` をブラウザで開くことです。

PWAとしてホーム画面に追加する場合は、GitHub PagesなどHTTPS環境に
`index.html`、`manifest.json`、`sw.js` をまとめて配置してください。

## 注意
- v0.1では手書き数式の完全自動認識は行いません。
- 最終解答のみ自動採点し、途中式は模範解答と比較して自己評価します。
- 学習データはブラウザのlocalStorageに保存されます。
